删除历史数据？

将删除所选时间范围内的记录，并把无引用图片移入 Windows 回收站。

  • 任务记录
  • 用户上传图
  • 用户生成图
  • 生成失败等无用记录
  • 未被引用的上传图片

固定案例、案例图片及案例配置不会删除。

记录删除后无法恢复；图片可从 Windows 回收站恢复。
清理无效记录

清理失败和已删除记录？

这些记录不会再继续生成，可以安全从历史列表移除。

  • 失败记录0 条
  • 已删除记录0 条
  • 合计0 条

成功记录、进行中任务、部分成功和待回补记录不会删除；仍被案例、草稿、画布或收藏引用的图片也不会删除。

记录删除后无法恢复；无引用图片会在后台移入 Windows 回收站，失败时自动重试。
